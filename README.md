# Software FJ - Sistema de Gestión de Clientes, Servicios y Reservas

Proyecto en Python (POO + manejo avanzado de excepciones), sin base de datos.

## Ejecutar
    python main.py

## Archivos
- excepciones.py: excepciones personalizadas
- logger.py: registro de eventos y errores en logs.txt
- entidades.py: clase abstracta EntidadBase y Cliente
- servicios.py: Servicio (abstracta), ReservaSala, AlquilerEquipo, AsesoriaEspecializada
- reserva.py: clase Reserva (confirmar, cancelar, procesar)
- main.py: simulación de 19 operaciones válidas e inválidas
